**Q1.** `High`  
In a two-pass assembler, the symbol table is built during

(1) Pass 2  
(2) the loading phase  
(3) Pass 1  
(4) both passes equally  

<details><summary>Answer</summary>

**(3)** — Pass 1 assigns addresses using the location counter and records every label in SYMTAB; Pass 2 uses it to generate code.

</details>

**Q2.** `High`  
The main reason for using a two-pass assembler is to handle

(1) macro expansion  
(2) dynamic linking  
(3) relocation  
(4) forward references  

<details><summary>Answer</summary>

**(4)** — A symbol may be used before it is defined; Pass 1 collects all definitions so that Pass 2 can resolve every reference.

</details>
