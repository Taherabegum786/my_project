# Provably Secure Butterfly Key Expansion from the CRYSTALS Post-Quantum Schemes (IACR ePrint 2024/946, 2024)
url: https://eprint.iacr.org/2024/946
read: abstract-only
problem: Provisioning pseudonymous certificates (Butterfly Key Expansion, BKE, a tripartite protocol) with post-quantum security.
method: Extends CRYSTALS Kyber and Dilithium with public key expansion (deriving pseudonymous public keys from a single public key); defines unforgeability and unlinkability as cryptographic games and proves them for BKE with the modified schemes; implemented by modifying Kyber and Dilithium in LibOQS; reports parameter choices and performance.
