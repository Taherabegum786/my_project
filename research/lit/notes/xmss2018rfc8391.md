# XMSS: eXtended Merkle Signature Scheme (RFC 8391 2018)
url: https://www.rfc-editor.org/rfc/rfc8391.txt
read: full
problem: Specifies XMSS and multi-tree XMSS^MT, stateful hash-based signatures with WOTS+ one-time keys.
method: Merkle tree of height h over WOTS+ keys (w=16). Signature = idx_sig (4 B) || r (n B) || WOTS+ sig (len*n B) || auth path (h*n B). Public key = OID || root || SEED.
numbers: Signature size formula stated: 4 + n + (len+h)*n bytes. Table 3 |Sig| (n=32, len=67, w=16): XMSS-SHA2_10_256 2,500 (smallest set, h=10, 2^10 sigs); _16_256 2,692; _20_256 2,820. n=64 (len=131): _10_512 9,092. Public key for XMSS-SHA2_10_256 = 68 B, DERIVED by me (OID 4 B assumed from the XDR format, + root 32 + SEED 32), not tabulated. Table 3 units not labelled in text; consistent with bytes by the formula. Sign cost 5,725 hash calls, verify 1,149 (h=10).
limits: Stateful; no benchmark on constrained devices; no broadcast or loss-tolerance treatment.
use-for: benchmark, framework
